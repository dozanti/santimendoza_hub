# Dozanti

Source for [dozanti.com](https://dozanti.com/) — the home of Dozanti and Santiago Mendoza, Backend Engineer. Built with React, TypeScript, and Vite.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

## Content

Profile, skills, social links, and project data live in `src/data/profile.ts` — edit there, not in the components.
